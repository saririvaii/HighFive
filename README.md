# HighFive 🙋🏻‍♀️

aiming for a real-time finger and hand gesture detection project that uses computer vision to identify, track, and interpret your hand movements — from simple finger counts to gestures.

Using your webcam, the system detects hand landmarks, highlights active fingers, and recognises custom gestures in real time. The goal is to make human–computer interaction more natural, playful, and intuitive, turning your hands into a language your computer understands!

---

### Features

* Real-time finger tracking and visual highlighting
* Detects gesture patterns (e.g. 1, 2, peace, rock, thumbs-up)
* Displays live feedback on the camera feed
* Lightweight and runs on most laptops
* Expandable — supports training your own gesture recogniser

---

### Tech Stack

**Languages:** Python (core), JavaScript *(optional for web demos)*
**Libraries:** OpenCV, MediaPipe, NumPy, TensorFlow/PyTorch *(optional)*
**Extras:** Streamlit for live apps, React/Next.js + TensorFlow.js for browser demos
